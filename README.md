# Task Manager App

A simple React-based Task Manager application to add, edit, delete, filter, and sort tasks.  
This project was built as part of a 7-day React learning roadmap.

## 🚀 Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed or pending
- Filter tasks (All / Completed / Pending)
- Sort tasks (A–Z / Z–A)
- LocalStorage persistence (tasks remain saved after refresh)

## 🛠️ Tech Stack
- React (Hooks: useState, useEffect)
- JavaScript (ES6+)
- CSS for styling
- LocalStorage for data persistence
